# NEO Songs

Готов Next.js проект за качване във Vercel.

## Най-бързо:
1. Разархивирай папката.
2. Качи съдържанието в GitHub repo.
3. Във Vercel: Add New → Project → избери repo → Deploy.

Забележка: този пакет съдържа интерфейса. Реалната ACE-Step генерация трябва да се свърже отделно към backend/API.
